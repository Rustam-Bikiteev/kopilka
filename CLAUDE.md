# Копилка (PWA) — состояние проекта

Живой сайт: https://rustam-bikiteev.github.io/kopilka/
Репозиторий: https://github.com/Rustam-Bikiteev/kopilka (публичный, ветка `main`).
**Push в `main` = автодеплой** (`.github/workflows/pages.yml`). Перед push спрашивать пользователя.

Общение с пользователем — только на русском.

## Стек

- Vite 8 + TypeScript, без фреймворка.
- Физика: `@dimforge/rapier2d-compat` 0.20. Рендер: PixiJS 8.20, все текстуры рисуются через canvas2D.
- PWA: `vite-plugin-pwa` (autoUpdate, SW кэширует всё, бандл ~2,6 МБ из-за wasm внутри rapier-compat).
- Звук синтезируется (`audio.ts`, модальный синтез), записанных сэмплов нет.
- Данные: `localStorage` ключ `kopilka.v1` (банки, монеты, тема), фото целей в IndexedDB `kopilka/photos`.

## Главный инвариант

**Сумма номиналов монет в банке (+ очередь `pending`) всегда равна балансу.**
- Пополнение раскладывается `greedy` по всем номиналам (1 ₽ … 1 МЛН).
- Переполнение (`fill > MAX_FILL`) → `compact()`: мелочь сплавляется в крупное, стоимость сохраняется. Выкидывать монеты нельзя.
- Снятие → `planWithdraw`: монеты вылетают через прорезь, сдача падает обратно.
- При загрузке банка `reconcile()` досыпает или убирает разницу (старые сохранения).
- Редкая монета (тип 7, `LUCKY`) стоит 0 ₽, не снимается.

Номиналы (индекс типа → значение): 0:1, 1:5, 2:10, 3:50, 4:100, 5:500, 6:1000 (слиток), 7:редкая, 8:5000, 9:10К, 10:50К (серебро), 11:100К, 12:500К (серебро), 13:1 МЛН (розово-золотой). Индексы менять нельзя: они лежат в сохранениях.

## Что умеет (на 2026-09-16)

**Главный экран (меню и листа настроек нет):**
- Шапка: название цели и сумма цели правятся прямо на месте, баланс уменьшается шрифтом при длинных числах, прогресс, точки копилок, «+» создаёт новую копилку и ставит курсор в название.
- Колонка справа (под большой палец): смена копилки по кругу, наклон, фото цели (второе нажатие убирает фото), тема по кругу.
- Низ: +10/+50/+100/+500, «Своя» (окно наверху: «Снять» / «Положить», лимит 10 млн за раз), «Встряхнуть», большая монета (держать — сыпать), «Обнулить» (второе нажатие; на пустой копилке при нескольких копилках — «Удалить»).

**Механики:**
- Физика падения, наклон телефона (на десктопе перетаскивание, стрелки), тряска (пробел).
- Склейка мелочи в крупное, комбо, редкая монета (4 % при пополнении).
- Снятие переворотом: 0,5 с вверх дном → монеты вылетают через прорезь; на десктопе клавиша F. Подсказка про переворот показывается один раз.
- После любого снятия 6 секунд плашка «Вернуть».
- Фото цели проявляется по мере накопления; праздники на 25/50/75/100 %, карточка «Цель достигнута».
- Свайп по шапке листает копилки.
- Только книжная ориентация: `screen.orientation.lock` там, где можно, иначе заглушка «Поверни телефон». Зум двойным тапом и щипком запрещён.
- Иконки PNG 192/512, maskable 512, apple-touch 180.

## История решений пользователя

- Стиль «стеклянная банка», тёплый тёмный фон (вариант 1), потом добавлены 4 темы.
- Звуки-колокольчики «бесят» → только мягкое звяканье монет, высокие звуки не возвращать.
- Приложение простое: никаких меню, всё на главном экране.
- Подсказку «Держи, чтобы сыпать» убрали, само удержание большой монеты оставили.
- Управление — справа под большой палец, не вверху.
- Максимальный номинал — 1 млн, должен быть виден в банке.

## Известные ограничения / идеи

- Больше ~50–100 млн: слитки 1 МЛН дальше не сплавляются, банка переполняется.
- Запрет зума, переворот и звук проверены только в браузере на ПК, на реальном телефоне Claude их не проверял.
- В Actions предупреждение про Node 20 (actions v4), на сборку не влияет.
- Записанных звуков монет нет: для них нужны аудиофайлы (скачивание — с разрешения пользователя).
